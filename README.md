# MICO

A desktop-first microbot swarm command center inspired by the high-energy hero-lab feel of **Big Hero 6**. The interface is built with plain HTML, CSS, and JavaScript so it can run anywhere without a build step.

## Run locally

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Then open `http://localhost:4173`.

## Included interactions

- Deploy and recall the 128-unit swarm
- Switch between Orbital, Shield, and Bridge formations
- Run a diagnostic scan with a results modal
- Expand the swarm visualization into a focused view
- Toggle autopilot, view live activity, and watch the 06:00 AM lab clock tick
